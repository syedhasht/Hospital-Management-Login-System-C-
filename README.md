# Hospital-Management-Login-System-C-
Description:

This is a simple C++ console-based hospital login system with three user roles: Admin, Doctor, and Patient. Each user type can register and log in to view their details. The system uses object-oriented programming and basic console I/O.

Features:

Admin registration and login

Patient registration and login

Doctor registration and login

Simple, menu-driven interface

Uses classes and OOP in C++
